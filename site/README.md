# Сайт нормативного обеспечения ИИ в РФ — FastAPI + PostgreSQL

Стартовый многостраничный сайт-каталог нормативных документов РФ по искусственному интеллекту.
Структура сайта сделана по схеме из draw.io: стратегический уровень, законодательный уровень, господдержка, стандартизация, отраслевые контуры.

## Что внутри

- FastAPI-приложение с Jinja2-шаблонами.
- Красивые HTML-страницы и CSS.
- Подготовленная структура проекта.
- Модели SQLAlchemy под PostgreSQL.
- Черновая структура БД: категории, документы, теги.
- Временные demo-данные, чтобы сайт запускался даже без БД.

## Быстрый запуск без PostgreSQL

```bash
python -m venv .venv
.venv\Scripts\activate  # Windows
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Открыть: http://127.0.0.1:8000

## Запуск с PostgreSQL через Docker

```bash
docker compose up -d
copy .env.example .env
uvicorn app.main:app --reload
```

Дальше можно подключить Alembic и сделать миграции.

## Страницы

- `/` — главная страница.
- `/catalog` — каталог документов.
- `/documents/1` — карточка документа.
- `/structure` — структура нормативного обеспечения.
- `/standards` — страница стандартов ГОСТ/ПНСТ.
